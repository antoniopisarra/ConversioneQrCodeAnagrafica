## English

**Name:** Conversione QR Code Anagrafica  
**Tags:** C# · .NET Standard 2.0 · NuGet · MIT  
**Short description:** Convert the decoded JSON payload of an Italian Revenue Agency tax QR code into a simple C# contact model, including tax identifiers, address and SDI delivery details. Local processing, a focused API and automated tests.  
**Origin:** An original project by Antonio Pisarra, made by Logical Flow. Created in 2020 and updated in 2026.  
**Note:** Requires already-decoded text; does not scan QR images or validate tax data.
